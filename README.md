# Python MySQL Task Manager

A command-line task management application built using Python and MySQL.

## Features

- Add new tasks
- View all tasks
- View pending and completed tasks
- Update task details
- Update task status
- Set task priority
- Search for tasks
- Filter tasks by priority
- Delete tasks
- Store and manage tasks using MySQL
- Display tasks in formatted tables

## Technologies Used

- Python
- MySQL
- mysql-connector-python
- Tabulate

## Project Overview

This project was created as a school-level Python and MySQL project to practice programming, database operations, and connecting Python applications with a MySQL database.

The application provides a menu-driven interface for creating and managing tasks.

## Database

The project uses a MySQL database to store task information such as:

- Task description
- Due date
- Status
- Date created
- Priority

## How to Run

1. Install Python.
2. Install the required Python packages:
   
   `pip install mysql-connector-python tabulate`

3. Set up the required MySQL database and table.
4. Update the database connection details in the Python file.
5. Run the Python program.
